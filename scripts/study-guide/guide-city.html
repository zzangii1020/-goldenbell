추천사 · 머리말

p.11–18
핵심 — 추천사를 쓴 최재천 교수는 이 책에서 “생물학의 결”을 본다. 필자는 건축물이 그 나라와 시대의 단면이며, 인간의 이성적·감성적 행동의 결집체라고 말한다.
  • 추천사(최재천): 건축은 전형적인 통섭 분야. 도시는 유기체, 좋은 건축물은 소주가 아니라 포도주. 개미와 꿀벌 비교. 보스턴 코먼이 센트럴 파크보다 안전 — 공원 폭은 충분히 좁고 내려다볼 건물이 있어야. (p.11–13)
  • ★ 교보문고 앞 “사람은 책을 만들고 책은 사람을 만든다” → “사람은 도시를 만들고 도시는 사람을 만든다”(5장 부제와 같은 맥락). 광화문 광장을 옛 저잣거리처럼 만들 구상이 있었다는 소문. (p.13)
  • ★ 피라미드: 공사 인부를 위한 도시를 건설하고 왕족과 같은 최신 의료 서비스를 주며 지음 → 건축 기술 + 사회·의료·경제의 결정체. “건축물은 사람이다.” (p.15–16)
  • ★ 괴테 “건축은 얼려진 음악”(리듬·멜로디·화음·가사). 건축만의 전달 매체 = 비어 있는 보이드 공간. 윈스턴 처칠의 말처럼 공간은 다시 우리를 만든다. (p.16–17)
  • 필자가 학교 때 배운 과목 21개 → 우리 교육은 건축을 이해하기 좋은 환경. 머리말 2014년 12월. (p.17–18)

1장 · 왜 어떤 거리는 걷고 싶은가

p.21–46
핵심 — 걷고 싶은 거리는 휴먼 스케일의 체험을 준다. 필자는 이를 이벤트 밀도(100미터당 출입구 수)와 공간의 속도(면적×속도의 평균)로 정량화한다. 시속 4킬로미터에 가까울수록 걷고 싶다.
  • 걷고 싶은 거리 ≠ 성공적인 거리. 테헤란로 = 성공적이지만 걷기 싫음, 명동 = 둘 다. 세종로는 압도적 스케일로 상징성. (p.21)
  • ★ 걷는 속도 시속 4킬로미터, 자동차 시속 60킬로미터. ★ 4평방킬로미터 코너 수: 바르셀로나 2,025 vs 시카고 1,075(약 두 배). 유럽은 마차 길 → 결절점 자주, 미국은 자동차 → 큰 블록. (p.23–24)
  • ★ 이벤트 밀도: 상점 n개 → 선택 경우의 수 2ⁿ. 의미 셋: ①보행자에게 권력(주도권) 이양 ②변화의 체험(5미터마다 입구, 4.5초마다 새 쇼윈도 = 케이블 TV 채널 바꾸기) ③같은 거리도 매번 새로운 체험. 미국 대사관 앞(정문 하나) vs 홍대 앞. (p.25–27)
  • ★ 표: 명동 36 = 가로수길 36 > 홍대 앞 34 > 강남대로 14 > 테헤란로 8. 명동·가로수길은 테헤란로의 4.5배. (p.29)
  • ★ 명동: 일제 강점기 일본 도시 계획가가 가로변은 좁고 세로로 긴 필지로 구획, 50년대 재건축 때 대규모 PF 불가 → 작은 필지 유지. 합벽. 다섯 거리 중 유일한 보행자 전용 거리(폭 10미터). 점포 최소 폭 약 5미터. (p.30–31)
  • ★ 공간의 속도: 움직이는 개체의 운동에너지 E=½mv². 사진작가 김아타 「타임스퀘어」(셔터 속도를 길게 → 사람·차가 사라져 시간 정지). ★ 록펠러 센터 선큰가든: 여름 레스토랑, 겨울 스케이트장. (p.32–37)
  • ★ 공식 = (차도 면적×차 속도 + 인도 면적×보행 속도 + 데크·주차장 면적×1km/h) ÷ 전체 면적. ★ Ss: 홍대 앞 4.86 < 가로수길 5.41 < 명동 6.5 < 강남대로 47.96 < 테헤란로 52.03. 합친 순위 = 가로수길 > 홍대 앞 = 명동 > 강남대로 > 테헤란로(데이트 코스 선호 순서). (p.38–40)
  • 세종로: 16차선 → 10차선(샹젤리제와 같음)인데 걷기 싫은 이유 = 가게가 없고 데크가 없음, 대형 건물만 → 가운데를 보게 되어 광화문 광장이 늘 정치적 시위 공간. 해법: 건물 앞 한 줄 가게, 노천카페. (p.43)
  • 너무 느린 거리(4Ss 미만)는 런웨이처럼 부담. 걷고 싶은 거리 요소: 이벤트·물건·자연환경·사람(사람은 완성하는 요소). (p.44–46)

2장 · 현대 도시들은 왜 아름답지 않은가

p.49–68
핵심 — 옛 도시는 재료가 통일되고 형태는 지형에 맞춰 다양했다. 현대 도시는 크레인·철골로 대형화되고 수입 재료가 난무한다. 골목·하늘·발코니를 잃었고, 감정을 일으키는 건축이 부족하다.
  • 엽서 도시: 산토리니(흰 회벽), 토스카나(벽돌). 과거 건축은 휴먼 스케일(소달구지로 옮길 나무, 몇 사람이 드는 대들보). 피렌체·베니스 = 두오모 + 작은 건물의 강약 조화. (p.49–50)
  • 현대 도시 = 전 세계 수입 재료 → 통일성·컨텍스트 없는 카오스. 간판만 정리하면 뒤의 혼돈이 보임. ★ 서울은 가로수·잡초가 가려 주는 여름이 볼 만 → 아름다운 도시가 되려면 겨울에 아름다워야. (p.51)
  • ★ 도시 4분류(형태·재료): 단순·단순 = 아파트 단지 / 복잡·단순 = 산토리니 / 단순·복잡 = 논현동 뒷골목 / 다양·다양 = 청담동 플래그샵 거리. 보스턴 뉴베리 거리 = 붉은 벽돌 규제. (p.52–54)
  • ★ 르 코르뷔지에 ‘빛나는 도시’(파리 도심을 고층 아파트 단지로) → 우리 아파트 단지 계획. 공원을 얻는 대신 골목을 잃음. ★ 골목과 복도의 차이 = 하늘이 있느냐. (p.54–56)
  • ★ “빨래가 사라진 도시” 주범 = 발코니 확장법. 베니스·홍콩의 빨래. 보디가드 속옷 광고. 대안: 경사지·구릉지의 테라스. (p.57–60)
  • 스카이라인: “신은 지평선을, 인간은 스카이라인을 만든다.” 로마 = 돔의 곡선(돔 = 아치를 180도 회전). ★ 부르넬레스키: 목재를 적게 쓰는 구조법으로 피렌체 대성당 돔 → 인류 최초의 특허권. ★ 뉴욕 = 엘리베이터가 만든 스카이라인. 서울 = 북한산·관악산·남산 능선 → 연필을 떼지 않고 그릴 수 있어야. (p.61–65)
  • 감정 시장: 「비긴 어게인」(2014, 340만). ★ 필자의 예술 정의 = 인간의 감정을 일으키는 무엇. 코르뷔지에 “주택은 사람이 살 수 있게 하는 기계” → 기능은 두 바퀴 중 하나. 프랭크 게리 디즈니 콘서트 홀. (p.65–68)

3장 · 펜트하우스가 비싼 이유

p.71–93
핵심 — 공간은 권력을 만든다. 볼 수 있는 자가 권력을 갖고, 여러 단계의 보안을 통과해야 하는 공간일수록 중요해진다. 감시는 때로 안전을 만든다. 공간의 권력은 면적이 아니라 체적이다.
  • ★ 2013년 상반기 가장 비싼 아파트 = 성수동 갤러리아포레(82평, 54억 9913만 원, 평당 6700만 원, 45층). (p.71)
  • ★ 팬옵티콘(pan + opticon = 모두 본다): 제러미 벤담, 1791년 감옥. 1975년 미셸 푸코 『감시와 처벌』로 유명. 감시탑은 어둡고 죄수 방은 밝음 → 죄수는 스스로 감시. (p.72–75)
  • ★ 19세기 파리: 프랑스혁명 후 권력자의 걱정 → 방사형 도로망, 개선문 위 대포 몇 개로 봉기 제압. 방사형 = 권력 차등, 격자형 = 평등·민주적. 뉴욕은 격자 + 대각선 브로드웨이 → 타임스퀘어. (p.75–76)
  • 펜트하우스 = 모든 것을 내려다보고 자신은 안 보임 → 돈으로 공간의 권력을 삼. ★ 관음증 = 보이어리즘(영화관, 연극 극장, 인터넷 익명 댓글), 악플 = 밴덜리즘. (p.77–78)
  • ★ 옥탑방이 안 비싼 이유 = 보안 취약(옆 옥상에서 넘어옴). 타워팰리스 짜장면. 자금성: 여러 겹 벽, 좌우 대칭, 수공간(물을 건넘) = 다른 공간으로 넘어가는 장치 → 사신의 기가 눌림. 클럽의 문지기. (p.78–82)
  • 감시의 장점: ★ 센트럴 파크는 폭이 커서 밤에 약 85퍼센트가 감시 없는 우범지대, 보스턴 코먼은 작고 주변에서 내려다봄(둘 다 옴스테드). 학교 운동장 주변에 문방구·분식점 → 광장 + 보안(악어와 악어새). (p.82–86)
  • ★ 호텔과 모텔의 가장 큰 차이 = 창문의 크기. 모텔 = 항상 밤이기를 원함, 호텔 = 보고 보이기를 원함(파크 하얏트). 리차드 마이어 찰스 스트리트 아파트. 모텔 창문만 키워 호텔로. (p.86–89)
  • ★ 공간의 권력은 체적으로: 성 베드로 성당 천장 130미터 → 같은 면적 사무실의 20배, 발다키노 기둥 약 11미터. 필자는 경사 천장·복층을 권함 → 집도 체적으로 팔아야. (p.89–93)

4장 · 도시는 무엇으로 사는가: 뉴욕 이야기

p.97–119
핵심 — 도시는 태어나고 성장하고 쇠퇴하는 생명체다. 죽은 부분에 새 생명이 돋게 하는 것이 도시 재생이며, 건축 문화재는 하드웨어가 아니라 소프트웨어로 보아야 한다.

  • 아파트와 돼지: 돼지 = 남는 식량을 보존하는 기술(보신탕도), 아파트 = 환금성 높은 저장 수단 → 은퇴 후 처분. 고령화 → 도살을 기다리는 아파트 돼지. (p.234–235)
  • 재개발 = 새 도화지를 달라고 떼쓰는 아이. 가장 큰 이유 = 오래된 건축물이 없음. 200년 후엔 80년대 콘크리트 아파트가 고풍스러울지도 → 보존의 대상. 30년 된 단지의 나무. (p.235–237)
  • ★ 케네디 생가 = 30평형대보다 작음, 부엌은 15평형대. 50년간 미국 중산층 집 두 배 → 물건 → 악순환. (p.237–238)
  • 한옥 = 마당이 거실, 대청마루가 식탁 자리(쓰리베이). 툇마루 = 처마 아래 중간 공간(발코니는 신 신고 + 높은 난간). ★ 아파트 = 수목적 관계(방끼리 단절), 한옥 = 순환형. 제안: 모든 방이 거실 쪽 창문. 문 = 프라이버시 0, 창문 = 느슨한 관계. (p.239–244)
  • ★ 프리츠커상(1979, 하얏트 재단): 한국 0회, 포르투갈 알바로 시자, 일본 6회(한일전 6 대 0). 원인 = 아파트. 일본은 주택 수요로 소형 설계사무소 시장. (p.244–245)

14장 · 동과 서: 서로 다른 생각의 기원 (p.325부터)

p.325–340
핵심 — 동양은 관계와 비움, 서양은 절대 가치와 수학·기하학을 중시했다. 이 차이는 정원·종교 건축·집·음식·웹사이트까지 이어진다. 강수량의 차이는 벽의 건축과 지붕의 건축을 낳았다.
  • 유교의 효 = 관계 속 가치(바둑돌), 서양 = 십계명 같은 절대 선. ★ 노자 『도덕경』 11장 “그릇이 쓰임을 가지는 것은…” → 쓰임은 비움에서. (p.325)
  • ★ 교토 료안지(용안사) 선의 정원: 모래 파도 위 돌 15개, 어디서 봐도 14개만 → 일인칭 관점 디자인. 서양 정원 = 직사각형·원·사선. (p.325–327)
  • 서양의 절대적 가치: 플라톤 이데아·동굴의 비유, 샹그릴라·무릉도원(현세 어딘가). 피타고라스, 플라톤 아카데미 입학 조건 = 수학. ★ 판테온 = 평면·단면 모두 원, 하기아 소피아 = 돔 3개가 큰 돔 1개(삼위일체). 1453년 동로마 멸망 → 학자들 이탈리아 → 르네상스. (p.327–330)
  • ★ 개미집 = 동양(관계, 땅), 벌집 = 서양(기하학, 공중, 육각형 모듈). 극동아시아 = 유교·현생·충효, 유럽 = 사후 세계·이데아 → 피라미드·황금비율·판테온. (p.331–332)
  • 空間과 SPACE: space = cosmos(chaos의 반대, 수학적 규칙) → 서양 공간 = “수학적 규칙을 가진 비어 있는 것”, 동양 공간 = 공(空, 비움) + 간(間, 관계). (p.333)
  • ★ 한식 밥상(한눈에, 관계, 음식 궁합) vs 코스 요리(선형) → 구글 = 코스 요리, 네이버 = 밥상. 복잡한 시대엔 밥상 먹는 사람이 적응 → 우리 미래가 밝은 이유. (p.334–335)
  • 테이블과 마루: 신 벗고 올라가면 가까워짐(방어를 내려놓음, 냄새 허락) → 접대는 좌식 일식집. 쌀 = 강수량 → 진흙 → 신 벗는 문화. (p.336–337)
  • 장마와 건축: 유럽 돌 vs 동아시아 나무(석굴암·첨성대만 진품). ★ 벼 1,000 / 밀 800(책 표기 밀리리터), 벼 재배 면적 90퍼센트 아시아. 무른 땅 → 주춧돌 스폿 기초, 급경사 지붕, 긴 처마, 툇마루. ★ “유럽 건축은 벽, 동양 건축은 지붕.” 세계가 하나의 스타일 → 다양성 위기. (p.337–340)

15장 · 건축이 자연을 대하는 방식

p.341–375
핵심 — 건축이 자연을 대하는 방식은 극복·이용·대화 세 가지다. 가장 성숙한 방식은 자연을 동등한 대화의 상대로 보는 것이다. 옹벽과 울타리, 보이지 않는 벽은 자연과 사람을 가른다. 한국적인 것은 그 시대의 수요·기술·시간이 만든다.
  • ★ 성 베네딕트 채플(스위스, 페터 춤토르): 타원형 실린더, 평평한 마루와 경사 대지 사이를 비움 → 음향 공명, “땅의 소리를 들을 수 있는 교회”. ★ 세 방식: ①극복(아파트 축대) ②이용(경사면 객석) ③동등한 대화의 상대(채플, 정자). (p.343–347)
  • ★ 두 주택: 글라스 하우스(필립 존슨) = 벽이 모두 유리, 화장실만 원형 벽, 수십 에이커가 자기 땅 / 스미요시 주택(안도 다다오) = 중정을 지나야 방 이동, 비 오면 우산, 노출 콘크리트, 주인은 30년간 이사 안 한 “성자”. 안도 = 권투선수 출신, 더우면 더워야. (p.347–350)
  • ★ 아사히야마 동물원(홋카이도 삿포로 근처): 연 300만 명 이상, 동선을 복잡하게 → 좁은 공간을 넓게, 바다사자 아크릴 튜브, “건축의 승리”. 72억 명, 1950년 24억. (p.350–352)
  • ★ 잠수교: 한강 다리 31개. 폭격에도 쉽게 잇도록 짧은 교각, 수면에 가장 가까움, 장마철 저항을 줄이려 난간 없음, 유람선용 아치, 2층 반포대교. 자연에 져 주는 다리(징검다리). 마포대교 → 여의도 = 서울의 맨해튼. (p.353–355)
  • 시간의 이름: 입동(24절기) vs 11월 7일, 하버드(카펜터 센터) vs MIT(숫자), 정동진. 지명은 두 글자 한자 → 장소도 인격. 아파트 몇 동 몇 호 → 정체성 상실. (p.355–356)
  • 옹벽의 역사: 국토 70퍼센트 산지. ★ 정도전 배산임수. 서울 인구 15세기 초 10만, 구한말 25만(1785년 영국 5만 넘는 도시는 4개). 연탄 → 뒷산이 달동네(난곡동). 달동네 = 휴먼 스케일, 아파트 = 100세대 이상 → 계단식 택지 → 콘크리트 옹벽. 옹벽과 동 → 단절. (p.356–361)
  • ★ 보이지 않는 벽: 임대 단지 통학 구역, 행복주택 반대, 님비(Not In My Backyard). 결혼 정보 회사 등급. 경제 성공 원동력 = 신분 사회 철폐. 아메리칸 드림, 피로 사회. (p.361–364)
  • 울타리: 21세기 = 가장 많은 지주. 자연에는 경계가 없다. ★ 영국 귀족의 하하(Ha-ha) = 안 보이는 웅덩이 울타리. (p.364–366)
  • ★ 한국의 정자: 독락당 비교는 불공정(건폐율·용적률 5퍼센트 미만). 정자 = 수백 년 전 룸살롱? → 예(藝)로 도를 닦는 공간. ★ 일본 다도 = 매뉴얼(신사 20년마다 새로, 북동쪽 기둥은 북동풍 맞은 나무) vs 한국 = 임기응변, 휜 서까래, 조선 도공의 찌그러진 찻잔, 프랭크 게리 댄싱 하우스. (p.366–369)
  • 정자 = 벽 없이 기둥, 주춧돌 = 자연과 땅의 매개, 도가의 무위자연. 현대 = “불도저가 있으니 땅 모양을 바꿀 수 있다.” (p.370–371)
  • 한국적이란? 한국적 ≠ 조선적. 한옥 = 그 시대의 재료·기술(소달구지, 흙벽 → 처마, 곡선이 더 쉬움, 기와, 좁은 방 폭, 주춧돌, 마당 결혼식). 전통을 만드는 절대 재료 = 시간. 유홍준 “호화 주택 허용”. 북촌·강남 뒷골목의 가능성. (p.372–375)

맺음말

p.377–383
핵심 — 건축은 동굴에서 시작해 복잡한 대도시가 되었다. 강수량·기온·재료가 다양한 건축을 만들었지만 지금은 문화의 다양성이 사라지는 위기다. 그래도 비관하지 않는다. 우리 모두는 일종의 건축주다.
  • 모닥불 = 최초의 난방이자 조명. 농경 → 정착 → 상업 → 도시화. ★ 다양한 건축의 세 변수 = 강수량(지붕 모양)·기온(창문 크기)·건축 재료. (p.377–378)
  • 범선 → 도자기 무역 → 유럽 정원, 고흐. 하이브리드 문화 = 르네상스(동로마 학자), 갈릴레오. 물감이 너무 섞이면 회색. (p.378–379)
  • ★ 반지 디자이너와 자하 하디드(동대문디자인플라자)가 같은 소프트웨어 라이노 → 형태 만들기와 구축 순서가 뒤바뀜, 디자인 생태계 파괴. 포스트모더니즘·해체주의. (p.379–380)
  • 가장 편리·안전·평화로운 시대, 뉴스와 보험회사가 공간을 망침. 런던 석탄 오염 → 석유·내연기관으로 극복. 지금은 과도기(청소년기). (p.380–381)
  • 학기 말 채점 때 말로 설명 금지 → 건축은 말이 아니라 공간이 말함(알타미라 벽화). 19세기 의학은 과학, 건축은 예술을 택함. 건축 = 예술+과학+경제학·정치학·사회학. 이 책 = 비전공자에게 보내는 편지. 우리 모두는 건축주(2015년 2월). (p.381–383)
